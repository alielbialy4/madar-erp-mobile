# 02 — World-Class Reference Board

**Rule:** Borrow principles. Never copy brand colors, logos, or exact chrome.

Each MADAR area binds **Reference DNA** before redesign may proceed.

---

## Dashboard
**Reference DNA:** Linear density + Stripe restraint + Apple calm  
**Borrow:** Compact context strip; 1–2 hero metrics; exceptions band; one deliberate chart; dense activity feed  
**Do not copy:** Linear issue UI; Stripe marketing gradients  
**MADAR composition:** Command Center archetype

## POS
**Reference DNA:** Square / Toast operational maturity + Apple touch ergonomics + Linear density  
**Borrow:** Catalog primacy on phone; true split on tablet; persistent cart summary; deliberate payment workspace  
**Do not copy:** Exact Square chrome or Toast branding  
**MADAR composition:** Flagship operational + payment transaction flow

## Payments / Checkout
**Reference DNA:** Stripe Checkout seriousness (internal dashboard clarity)  
**Borrow:** Amount due dominance; method → account → allocation → remaining → confirm  
**Do not copy:** Stripe purple or Checkout marketing layout  
**Avoid:** Colored method wallpaper cards

## Sales (index)
**Reference DNA:** Stripe payments list + Linear rows  
**Borrow:** Invoice #, status, time, counterparty, amount; dense scanning  
**Do not copy:** Stripe logo treatments  
**Avoid:** Giant decorated invoice cards

## Sale detail
**Reference DNA:** Stripe payment detail + Shopify order document  
**Borrow:** Identity header; status; total; line items; financial summary; payments; timeline  
**Avoid:** Equal card grid of metadata

## Refunds
**Reference DNA:** Stripe dispute/refund clarity + bank transfer confirmation seriousness  
**Borrow:** Stepwise risk workflow; unmistakable final financial effect  
**Avoid:** Generic multi-field form wall

## Shifts
**Reference DNA:** Cash drawer control software maturity + Linear operational calm  
**Borrow:** Open/closed state; expected / counted / variance as related triad; then activity; then close  
**Avoid:** Six equal KPI cards

## Financial accounts (index)
**Reference DNA:** Stripe Balances / Connected accounts list  
**Borrow:** Name, type, masked id, balance dominance, subtle status  
**Avoid:** Settings-style tile grids

## Financial account detail
**Reference DNA:** Stripe balance detail + Linear metadata density  
**Borrow:** Large balance; quiet secondary; actions; banking-dense activity rows  
**Direction encoding:** sign + icon + label + type + color (never color alone)

## Expenses
**Reference DNA:** Stripe transactions + expense management tools  
**Borrow:** Clear incurred / paid / outstanding separation  
**Avoid:** Confusing paid amount with expense total

## Inventory
**Reference DNA:** IBM Carbon data density + Shopify inventory ops  
**Borrow:** Compact structured rows; exception semantics only for low/zero/negative  
**Avoid:** Giant stock cards

## Products
**Reference DNA:** Shopify Admin resource model + Polaris patterns  
**Borrow:** Search-first index; dense row (image, name, category, price, stock, status); progressive editor disclosure  
**Avoid:** Marketing-storefront aesthetics

## Purchases
**Reference DNA:** Shopify purchase orders + Stripe invoice document  
**Borrow:** Document composition; lines; subtotal / paid / outstanding  
**Avoid:** Card-per-field forms

## Suppliers / Customers
**Reference DNA:** Shopify customer/vendor + Stripe customer detail  
**Borrow:** Party header; key financial state; quick actions; transactions/activity  
**Avoid:** Endless equal cards

## Dining / Tables
**Reference DNA:** Toast / Square for Restaurants spatial ops + Apple state clarity  
**Borrow:** Table tile with number, status, elapsed, amount, waiter; subtle state color  
**Avoid:** Rainbow hall

## KDS
**Reference DNA:** Kitchen display systems (Toast KDS) + mission-control typography  
**Borrow:** Elapsed time dominance; items/modifiers; overdue attention via type/position before hue  
**Avoid:** Decorative chrome

## Delivery
**Reference DNA:** Delivery ops dispatch boards + Stripe status clarity  
**Borrow:** “Needs action now” band; status → party → area → driver → amount → time  
**Avoid:** Pretty map-first vanity (unless operationally primary)

## Reports
**Reference DNA:** Stripe analytics + Linear charts restraint  
**Borrow:** Header/scope; primary metrics; one trend; breakdown; detail  
**Viz palette:** cobalt + semantic + controlled neutrals — no rainbow donuts

## Settings
**Reference DNA:** Apple Settings + Linear preferences restraint  
**Borrow:** Grouped lists; strong section titles; boring excellence  
**Avoid:** Colorful icon wells and cards

## App shell / navigation
**Reference DNA:** Linear app shell + Apple HIG mobile ergonomics + Atlassian IA  
**Borrow:** Receding nav; compact headers; structured More modules; tablet rail  
**Avoid:** Icon candy grid as primary IA

---

## Binding rule

No module redesign may start without a row on this board.  
If DNA is unclear, stop and extend this document first.
