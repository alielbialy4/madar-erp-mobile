## Signature

The MADAR signature is a combination of:

1. **Obsidian / Midnight Navy structure** — deep canvas, controlled elevated materials  
2. **Electric Cobalt accent** — selected, primary action, focus, chart primary series  
3. **Precision typography** — distinct text vs numeric hierarchies  
4. **Financial value styling** — tabular, currency-aware, LTR isolation in RTL  
5. **Elegant sectional separators** — spacing → surface → divider before borders  
6. **Mature radius** — not bubble, not pill abuse  

**Not the signature:** giant gradients, glassmorphism, glowing borders, colorful blobs, rainbow modules.

---

## Color composition law

On a normal ERP screen:
- **~80%** controlled neutrals (structure)
- Brand cobalt: selection, primary CTA, focus, high-value anchors, primary chart series
- Semantic color: only where meaning exists (success/warn/danger/info/refund)

## Surface architecture

1. **CANVAS** — page background  
2. **SECTIONS** — spacing + typography grouping (default)  
3. **SURFACES** — subtle background shift when grouping needs mass  
4. **ELEVATED OVERLAYS** — sheets, menus, modals, sticky docks  

Cards only when the object is a true contained object (account summary, table order, alert).

## Border / elevation / radius

Hierarchy: spacing → background → type → divider → border → shadow  
Elevation only for floating chrome and overlays.  

Radius:
- Control: 8  
- Input: 10  
- Surface: 12  
- Sheet: 16  
- Pill: status / compact filters / segmented ONLY

## Motion
Subtle: sheet, press, tab, selection, expand, success ack.  
No bounce, long springs, decorative loaders.

## Anti-patterns (banned)
- Pastel KPI wells  
- Purple decorative accents  
- Card-per-row lists  
- Equal rainbow metrics  
- Stretched phone UI on tablet  
- Inverted-white dark mode  
- AI template gradients / mesh
