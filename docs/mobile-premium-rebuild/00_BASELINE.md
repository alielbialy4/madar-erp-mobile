## Current navigation model

- Phone: five destinations in a floating bottom dock — Dashboard, POS, Products, Sales, More.
- Secondary access: a full-height hierarchical drawer and command palette.
- Tablet: persistent sidebar appears only at width 900+, leaving large phones and smaller tablets in the phone architecture.
- Context controls: navbar exposes menu, branch selector, sync, search, notifications, and brand/profile affordances in one horizontal band.
- POS: underlying navigation becomes fullscreen and uses separate phone/tablet rendering.

## Existing visual foundations

- Typography: Tajawal roles exist, but many screens override sizes and weights inline.
- Spacing: 4/8/12/16/20/24/32 scale exists, with additional 40/48 values.
- Radius: multiple roles exist, but `xl`, `xxl`, `xxxl`, and pill are overused.
- Surfaces: theme tokens provide canvas, surface, muted surface, borders, and semantic states.
- Elevation: shared levels exist, but card and shadow use is widespread.
- Color: theme tokens are largely adopted; one active TSX file still contains direct hex usage.
- Lists: 28 screen files create local styles; 98 screen files contain inline style objects.
- Responsive: only 16 screen files directly inspect window dimensions.

## Runtime baseline

- Physical device available: Redmi Note 8 Pro.
- Android development client and Metro are operational.
- Portrait, landscape, light, and dark screenshots can be captured through ADB.
- Prior runtime review confirmed that visual consistency on one screen does not prove application-wide quality.

## Functional baseline gates

Before structural redesign work, the mobile baseline passes TypeScript, full ESLint, unit tests, UI adoption checks, and hardcoded-color checks. These gates must remain green throughout the rebuild.

## Freeze rule

Backend contracts, permissions, branch/tenant scope, financial calculations, stock accounting, offline semantics, idempotency, printing rules, and synchronization behavior are frozen unless a separately proven functional defect is found.
